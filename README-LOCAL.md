# تشغيل نظام معرض الزبيدي محلياً على Windows

## التشغيل اليومي
اضغط مرتين على:

`start-showroom.bat`

سيقوم الملف بتجهيز الحزم عند الحاجة، وبناء الواجهة، ثم تشغيل النظام وفتح المتصفح على:

`http://localhost:4000`

## البيانات
قاعدة البيانات المحلية موجودة في:

`server/data/showroom.sqlite`

ولا تحتاج إلى إنترنت أثناء الاستخدام بعد تثبيت الحزم وبناء الواجهة لأول مرة.

## النسخ الاحتياطي
النظام يحتوي على زر نسخ احتياطي لقاعدة البيانات. يفضّل الاحتفاظ بنسخة خارج مجلد المشروع أيضاً، مثل USB أو قرص آخر.

## ملاحظة
الإنترنت مطلوب فقط في أول إعداد إذا كانت حزم Node.js غير مثبتة على الجهاز. بعد تجهيز `node_modules` و`client/dist` يمكن تشغيل النظام محلياً دون اتصال بالإنترنت.

## تعديل الكفيل الاختياري
في بيع التقسيط يوجد الآن اختيار واضح "يوجد كفيل". عند إلغاء الاختيار لا تُرسل بيانات كفيل إلى الخادم، ولا يتم إنشاء سجل كفيل، وتظل بيانات الكفيل فارغة في مستندات العقد والكمبيالات.


## النسخ الاحتياطي التلقائي
- يعمل تلقائيًا بعد كل إجراء ناجح يغيّر بيانات النظام، بدلًا من الانتظار لنسخة مجدولة كل 6 ساعات.
- لا تُنشأ نسخة عند فتح الصفحات أو البحث؛ النسخ تبدأ بعد اكتمال عمليات الإضافة والتعديل والحذف والتحصيل وغيرها.
- النسخ تحفظ داخل `server/data/backups`.
- يحتفظ النظام افتراضيًا بآخر 30 نسخة تلقائية ويحذف الأقدم تلقائيًا.
- يمكن تغيير الإعدادات من متغيرات البيئة: `SHOWROOM_AUTO_BACKUP=0` لإيقافه، و`SHOWROOM_AUTO_BACKUP_RETENTION=60` لتغيير عدد النسخ المحتفظ بها.

## الدخول أول مرة

لا توجد كلمة مرور افتراضية. شغّل `start-showroom.bat`؛ في **أول تشغيل** يظهر في النافذة اسم المدير
(`admin`) وكلمة مرور عشوائية، وتُحفظ أيضًا في `server\data\FIRST-RUN-ADMIN.txt`.
ادخل بها، غيّرها من «المستخدمون والصلاحيات»، ثم احذف الملف.

**الفتح من أجهزة أخرى في المعرض:** تطبع نافذة التشغيل سطرًا مثل `http://192.168.1.20:4000`؛ افتحه من أي
جهاز على نفس الشبكة. وافق على رسالة جدار حماية ويندوز للشبكة الخاصة عند أول مرة. الاتصال HTTP داخل
الشبكة الداخلية فقط؛ لا تفتح المنفذ للإنترنت.

لحساب مدير طوارئ دائم (أو لو نسيت كلمة المرور) اضبط البيانات محليًا في PowerShell:

```powershell
$env:SHOWROOM_AUTH_USER = Read-Host "اسم المستخدم"
$secret = Read-Host "كلمة مرور قوية" -AsSecureString
$env:SHOWROOM_AUTH_PASS = [System.Net.NetworkCredential]::new("", $secret).Password
.\start-showroom.bat
```

لا تضع القيم في Git ولا ترسلها في المحادثات. للمعاينة ببيانات وهمية فقط، استخدم
`SHOWROOM_DEMO_MODE=1` مع `NODE_ENV=development`؛ تستخدم قاعدة `showroom-demo.sqlite`
منفصلة، ويظهر تنبيه أنها غير مخصصة لبيانات حقيقية.

## WhatsApp Web المحلي

للتشغيل المجاني التلقائي داخل جهاز المعرض: من صفحة «واتساب والتنبيهات» اختر «WhatsApp Web محلي (تلقائي)»، ثم شغّل المشروع. في أول تشغيل ستفتح نافذة WhatsApp Web وتظهر شاشة QR؛ امسحها من الهاتف مرة واحدة، وستُحفظ الجلسة محليًا داخل `server/data/whatsapp-web`. يستخدم النظام طابور إرسال بفاصل زمني محافظ قابل للتعديل من الإعدادات، ولا يوجد ضمان من واتساب لعدم تقييد الحساب لأن هذا عميل غير رسمي. يتطلب Node.js 18 أو أحدث. ملف `start-showroom.bat` يتحقق من تثبيت محرك WhatsApp Web تلقائيًا قبل التشغيل.

لتثبيت محرك WhatsApp Web: `npm --prefix server install`.
